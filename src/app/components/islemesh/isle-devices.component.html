Add or prepare a device

A device has joined when it has an Isle address and can reach Isle services. Hosting apps is a separate capability you can add later.

  1. Install the member tools. Use the versioned member package set supplied by this Isle. Match package versions and checksums before installation.
  2. Connect Ethernet to the Isle. Select the physical Ethernet port attached to the Isle. Reuse its existing connection profile and keep the normal internet connection.
  3. Verify access. Check the assigned address, Isle name resolution and trusted HTTPS. An address alone does not verify DNS or certificate trust.
  4. Choose what to host. Check the requirements of the app you want to install. Container apps, Polari apps, virtual machines and hardware bridges need different capabilities. Hardware bridges also need access to the intended hardware.
  5. Prepare and verify hosting. Enable only the required capabilities, then check a real app from another device. Refresh the inventory after setup.

These are setup steps, not an automatic installer. Device setup actions and verified app-placement checks will appear here when the corresponding management services are available.
